# HTML

## 结构

1. 版本

2. 头部

   1. /<title>标题
   2. /<meta>页面描述（不会显示在网页中）
   3. /<link>连接外部文档
   4. /<base> 所有相对链接的默认链接或目标（唯一）
   5. /<style>定义样式信息
   6. /<script>定义客户端脚本（代码）

3. 主体

   1. /<h1>……<h6>标题

   2. /<p></p>段落

   3. /<br>在不产生一个新段落的情况下进行换行（新行）

   4. /<a></a>链接

      ```html
      <a href="http://www.runoob.com">这是一个链接</a>
      ```

   5. /<ul><ol><dl>无序/有序/描述性列表

   6. /<table>表格

   7. /<div>元素容器（默认独占一行）

   8. /<span>元素组合

   9. /<image>图像

      ```html
      <img src="url" alt="some_text">
      ```

      

   10. /<video>视频

   11. /<canvas><svg>非矢量/矢量画布

       canvas和svg下还有很多笔刷控制等代码

   12. /<form>表单（控件区）

   13. /<script>客户端脚本
